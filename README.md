# 沪深300 五因子打分选股回测（v0）

在沪深300（剔除金融股）中用五个因子打分，每月选得分前 10 只等权持有，回测 2019–2024 年。结论：综合得分的 Rank IC ≈ 0，五分组收益不单调，策略年化 −0.22%，每年跑输同一股票池的等权组合（6.47%）约 6.7 个百分点；在样本内**未发现**显著的选股能力。

## 项目概述

用 Tushare 数据在本地复现唐宇迪《Python金融分析与量化交易实战》第 14 章（米筐平台）的因子打分选股策略。

- **股票池**：沪深300 历史成分股（月度快照），剔除金融股，每期约 245 只
- **区间**：2019-01 至 2024-12（首个调仓日 2019-01-31，收益从 2019-02 起计）
- **策略**：每月按五因子综合得分选前 10 只，等权持有到下一个调仓日
- **检验**：除回测外，还做了 Rank IC、五分组回测、交易成本、分年度和前后半段检验

## 数据

- **来源**：Tushare Pro
- **股票池**：沪深300 **月度历史成分股**（`index_weight`），避免只用当前成分股带来的幸存者偏差
- **剔除金融股**（银行、证券、保险、多元金融）：金融股的负债主要是存款，是经营的"原材料"而非财务风险，资产负债率普遍在 90% 以上，会被机械地排到末尾；同时 PB 普遍低于 1，又会被机械地排到前列。两者反映的都是行业报表结构，而不是公司质量
- **行情**：日线 + 复权因子 → 后复权价格
- **财务**：`fina_indicator`，按**公告日** `merge_asof` 对齐到调仓日（公告当天的财报不算），避免未来函数
- **估值**：`daily_basic`（PB、总市值）
- **清洗**：
  - 稀释 EPS 缺失约 6%，集中在没有可转债等稀释性证券的公司（此时稀释 EPS = 基本 EPS），用基本 EPS 补齐，而不是删除这些股票
  - 已退市股票的行业字段缺失，导致 3 只金融股混入股票池；排查缺失值后手动修正
  - 财务指标的重复行去重

## 方法

- **因子**：EPS（稀释 EPS，缺失时用基本 EPS）、ROE（EPS 和 ROE 均按报告期年化）、资产负债率、PB、总市值
- **打分**：每个调仓日在横截面上对每个因子排名，名次相加得到综合得分。方向：EPS、ROE 越高越好；资产负债率、PB、总市值越低越好
- **组合**：月度调仓，选得分前 10 只等权持有。日收益 = 前一日权重 × 当日收益
- **自检**：手算第一期收益与代码结果一致；"股票池全部等权"对照组流程正常；五组平均收益与等权组合的日差 < 0.0001

## 结论

1. **打分没有表现出预测力。** 综合得分 IC 均值 −0.003，五个因子 |IC| 均 < 0.02、t 均 < 1；五分组收益不单调，G5−G1 为 −5.51%，月度 t = −1.12，统计上不显著。
2. **正确的基准是股票池等权。** 它和策略来自同一个股票池、同样等权，两者之差才是打分规则的作用；策略每年跑输约 6.7 个百分点（−0.22% vs 6.47%）。沪深300 是自由流通市值加权、且含约 1/4–1/3 权重的金融股，和它比较会混入加权方式和股票池的差异。
3. **不是交易成本造成的。** 费后策略 −1.01%、等权 6.39%，成本每年拖累不到 1 个百分点，远小于 6.7 个百分点的差距。
4. **不是市场环境造成的。** 2019–2021 和 2022–2024 两段都跑输等权，牛市熊市都一样。
5. **回撤更深来自集中持仓。** 只持 10 只，波动率 24.4% vs 20.1%，最大回撤 −53.7% vs −37.7%。打分接近随机时，策略近似于"从池子里随机抽 10 只"，期望收益接近等权、但波动大得多，所以跑输的幅度里也可能有相当一部分来自运气。
6. **PB 是风格因子。** PB 的年度 IC 2019、2020 年为 +0.11、+0.14，2021、2023 年为 −0.12、−0.18，方向随成长/价值风格切换，这也是它 IC 标准差最大的原因。
7. **不为跑赢而调参。** 反向选低分组同样不显著，而且分组不单调。看过样本结果再改规则，会把样本内的噪声当成规律，到样本外就会失效，而且没有新数据可以验证，所以保持原规则不变。

## 缺陷与改进方向

| 缺陷 | 对结果的影响 | 改进 |
|---|---|---|
| 每日调回等权：回测假设每天免费把权重调回 10%，真实做法是月内持有不动 | 日频再平衡相当于"卖涨买跌"的反转交易，A 股短期反转明显，加上收盘价在买卖价之间跳动，收益大概率被**高估**；量级小，且等权对照组和分组用同样算法，相对比较基本公平 | 月内按买入持有计算权重漂移 |
| EPS 不可横比：每股指标取决于股本大小 | 排名部分反映股本和股价水平，而非盈利能力；方向未知 | 换成 EP（EPS / 股价） |
| 年化的季节性：四季度常集中计提减值、确认费用，用前三季年化会偏高；同一调仓日不同公司所用报告期不同 | 用季报年化的公司 EPS/ROE 被高估、排名偏前，偏差在公司之间不一致 | 改用 TTM（滚动四个季度） |
| 只持 10 只 | 不改变期望收益，但放大波动和个股风险，结果可靠性低；持约 50 只的 G5 也只有 3.89%，多持股救不了这个打分 | 增加持股数，或直接用分组组合 |
| 基准不含分红：沪深300 是价格指数，策略和等权用后复权价（含分红） | 指数每年少算约 2% 分红，被低估，策略相对指数的表现被**高估** | 换成全收益指数 H00300 |
| 无风险利率设为 0 | 所有组合的夏普都被**高估**；无风险利率约 2%、波动 20% 时，夏普约少 0.1 | 用国债或 Shibor 利率 |
| 未纳入 ROIC（原策略有） | 复现不完整，和原策略因子不一致；影响方向未知 | 补上 ROIC 因子 |
| 未做行业中性化 | PB、资产负债率等存在行业差异，全池排名时得分部分是行业押注；剔除金融股只解决了一个行业的问题 | 每个调仓日在行业内排名（`groupby(['trade_date', 'industry'])`） |
| 002602.SZ 缺财务数据（end_date），已剔除 | 剔除前后重跑结果完全一致，无影响 | — |
| 取数无完整性校验 | 循环逐只取数时，接口报错有记录，但返回空表或行数不全不会报错，可能静默缺股；影响方向未知 | 拉完后核对应有/实有股票集合、每只股票行数 vs 交易日数，失败自动重试 |

## 如何复现

1. `pip install tushare pandas numpy matplotlib`
2. 用自己的 token 运行一次 `ts.set_token('你的token')`（见 `0-Settings`），代码里只用 `ts.pro_api()`，不写 token
3. 运行 `1-数据拉取`：生成成分股权重、日线、复权因子 csv
4. 运行 `Project 0-因子打分`：继续拉取估值、财务、指数数据，然后依次完成清洗、打分、回测和全部检验
5. csv 均未上传（约 100MB），按以上步骤可重新生成
6. 需要 Tushare 积分 ≥ 2000
